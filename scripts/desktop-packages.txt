# (scripts/build-desktop-rootfs.sh). One package per line; "#" starts a comment.
# The Master Blueprint (section 5) puts the screen stack, the editor and the
# compilers inside the Debian tree, and the app is meant to work the moment it is
# installed, so none of this is downloaded on the phone. Package-manager content
# (npm modules, pip packages, composer packages) is NOT here: as on a PC, those
# arrive with the user's own commands.
#
# Size is not the constraint here, the unpack time on a phone is: remove a
# language you do not ship rather than trimming the screen stack.
